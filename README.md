SQL E-Commerce Analysis

Project Overview

This project is an intermediate-level SQL analysis of an e-commerce sales dataset.

The project is designed to build practical SQL skills by answering business questions using relational data from customers, orders, products, and order items.

The analysis progresses through different levels of SQL questions, moving from basic queries to more advanced business analysis.

Dataset

This project uses a synthetic e-commerce dataset created for SQL practice and portfolio development.

The repository contains the following datasets:

- "customers.csv" — customer information
- "employees.csv" — employee information
- "orders.csv" — customer order information
- "order_items.csv" — products and quantities included in orders
- "products.csv" — product information

Project Objectives

The main objectives of this project are to:

- Practice writing SQL queries
- Analyze e-commerce sales data
- Understand relationships between database tables
- Answer business questions using SQL
- Calculate sales and customer revenue
- Analyze customer purchasing behavior
- Analyze products and product categories
- Practice SQL joins and aggregate functions
- Progress from basic SQL queries to business-level analysis

How to Use This Project

1. Clone or download the repository.
2. Import the CSV files into your SQL database.
3. Create the required tables using the appropriate schema.
4. Run the SQL queries in the "SQL" folder.
5. Review the query results and business insights.
